## 🚀 How to Run the Notebook

1. Clone or download this repository.
2. Install Python if it is not already installed.
3. Install Jupyter Notebook using:

   ```bash
   pip install notebook
   ```

4. Open a terminal in the project folder.
5. Run:

   ```bash
   jupyter notebook
   ```

6. Open `Python_Module.ipynb` and execute the cells one by one.

Alternatively, upload the notebook to Google Colab and run it in your browser.
